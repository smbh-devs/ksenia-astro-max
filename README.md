# ksenia-astro-max

Одностраничный лендинг «Ксения | Астролог», хостится на GitHub Pages под доменом `ksenia-astro-max.ru`.

## Файлы

- `index.html` — страница целиком (стили inline, без сборки)
- `ksenia.webp` — фото
- `CNAME` — кастомный домен для GitHub Pages
- `.nojekyll` — отключает Jekyll-обработку

## Яндекс Метрика

Счётчик `112717238` стоит в `index.html`: сниппет в `<head>`, noscript-фолбэк в начале `<body>`.
Вебвизор, карта кликов и `trackLinks` включены в `init`.

Цели (создать в Метрике как «JavaScript-событие»):

| Идентификатор | Когда срабатывает                          |
|---------------|--------------------------------------------|
| `cta_click`   | клик по кнопке «Получить бесплатный разбор в MAX» |

Переход на `max.ru` дополнительно виден в отчёте «Переходы по внешним ссылкам» (через `trackLinks`).

## Деплой

Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
После первого деплоя в Settings → Pages включить **Enforce HTTPS** (появится после выдачи сертификата, обычно до часа).
